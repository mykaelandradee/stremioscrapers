<h1 align="center">MegaSource Stremio Addon</h1>

<p align="center">
Run your preferred Python scripts with MegaSource.
</p>

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/zoreu/megasource_stremio.git

cd megasource_stremio
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---


## 💻 execute the project

Start the server:

```bash
python app.py
```

---

## disclaimer

MegaSource does not run scrapers internally; each user can set up their own scrapers to run with the addon. Therefore, we are not responsible for any misuse of the tool.
